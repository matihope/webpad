# 0001: Rust for the server

**Status:** accepted, 2026-11-01

## Context
The server injects virtual gamepads on Windows, Linux and eventually macOS, and needs low, steady latency. The user chose between Go and Rust.

## Decision
We use Rust with tokio and axum. Static web assets are embedded with `rust-embed`.

## Consequences
- The crates we need are mature: `vigem-client` (Windows), `evdev` with uinput (Linux) and `enigo` (keyboard).
- The app ships as a single binary with the web UI inside. In debug builds, `rust-embed` reads `web/` from disk, so UI edits only need a page reload.
- OS-specific code goes behind `#[cfg(target_os)]`.
